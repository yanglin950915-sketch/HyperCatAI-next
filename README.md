**以 AI Agent 为核心的 Android 智能助手，背屏 AI 萌宠是可选的陪伴与交互扩展。**

HyperCat AI 的主要目标是把大模型对话、语音交互、个人记忆和手机工具能力整合到 Android 应用中，让用户可以通过文字或语音与 Agent 交流，并在明确授权后调用系统功能。小米 Pro 系列背屏萌宠是后续计划完善的个性化陪伴功能，但不是项目的核心定位，也不影响主 Agent 功能独立使用。

> **背屏状态：v0.9.21 开始提供 REAREye 组件接入与 Agent 状态双向同步。** 需要在兼容的小米背屏设备上通过 REAREye 导入组件并添加卡片；不同机型的安全区、AOD 和实际触摸行为仍以实机验证为准。

## 项目定位

- **主线：AI Agent。** 负责理解用户请求、模型对话、记忆管理、语音交互，以及经授权的手机工具调用。
- **扩展：背屏 AI 萌宠。** 通过 REAREye 将 Agent 状态、回复和触摸互动同步到兼容设备背屏。
- **平台：Android。** 以 Kotlin 和 Jetpack Compose 构建，主屏 Agent 与 REAREye 背屏组件共用状态仓库。

## Agent 核心能力

### 大模型对话与配置
- 支持配置兼容 OpenAI API 格式的模型服务。
- 推理模型与 TTS 语音模型分别配置、选择和管理，拥有独立的模型档案及连接参数。
- 支持保存多个模型配置，按需切换或删除。
- 对话支持模型回复、思考内容展示及代码内容的独立呈现等交互体验。

### 记忆与个性化
- 可通过对话明确要求 Agent 记住信息。
- 支持查看、添加、删除单条记忆及清空记忆。
- 已保存的记忆可作为后续对话上下文使用。

### 语音交互与 AI 通话
- 支持回复语音朗读，并可单独控制自动朗读开关。
- TTS 与推理模型分开设置；可使用支持的第三方 TTS 服务。
- 提供应用内语音识别交互和 AI 语音通话界面。
- AI 视频通话支持摄像头预览，并将间隔采集的画面交给视觉模型分析。

> 当前视频交互采用摄像头预览和间隔采帧分析，并非连续双向视频流或 WebRTC 实时音视频通话。语音识别能力依赖 Android 设备上已安装并启用的识别服务；语音播报则依赖已配置且兼容的 TTS 服务。

### 系统工具
Agent 可根据用户请求调用 Android 系统能力或外部数据服务，包括：
- **闹钟：** 调用系统闹钟应用创建/设置闹钟，由用户确认。
- **日历：** 调用系统日历新建事件页面，由用户确认保存。
- **天气：** 支持 Open-Meteo、高德地图和​​彩云天气三种服务，用户可在设置中自主选择；高德 Key、彩云 Token 分别独立保存，也可使用免密钥的原有 Open-Meteo。支持当前位置和城市/区县查询。
- **手机基础操作：** 可选接入 Android 无障碍服务，支持返回、主页、通知栏、快捷设置、滑动和按文字点击等简单操作。

系统操作必须遵守 Android 权限与用户授权。无障碍服务需要用户在系统设置中主动启用；未授权时不会执行对应操作。无线调试/ADB 控制不应被视为当前版本已具备的能力。

## 背屏 AI 萌宠（REAREye 接入）

背屏与主屏 Agent 共用同一份萌宠状态。主应用通过只读 ContentProvider 暴露名称、情绪和最新回复；REAREye 的 MAML 组件负责刷新数据，WebView 负责离线绘制表情与触摸区域。触摸动作通过 MAML WebView 内部 Trigger 回传 Android 广播，再写回主应用的状态仓库。

- **主屏到背屏：** Agent 思考状态、最终回复、天气/系统操作结果和萌宠名称/情绪。
- **背屏到主屏：** 摸摸、思考、休息三种触摸动作；主应用运行时同步更新，未运行时先持久化，启动后恢复。
- **显示适配：** 976×596 横向设计基准、左侧摄像头避让区、DPR 画布和实际 WebView 视口缩放；AOD/暂停时停止动画。
- **离线资源：** HTML、CSS、JavaScript 内联在一个文件中，不依赖 CDN、外部字体或在线图片。

### REAREye 导入

1. 从 GitHub Release 下载 `HyperCatAI-rearscreen-v0.9.21.zip`。
2. 在 REAREye 的「背屏中心 → 背屏个性化 → 组件模板管理器」导入 ZIP。
3. 在「卡片管理器」添加对应组件卡片并启用。
4. 安装/更新 HyperCat AI v0.9.21 后，确认 REAREye 能读取 HyperCat AI 的背屏状态 Provider。

> 首次接入仍需在目标设备验证 WebView 视口、摄像头避让、MAML Provider 读取、广播回传和 AOD 恢复；若设备型号或系统版本不同，应以实测数据调整布局参数。

## 权限与安全说明

- 麦克风、摄像头和位置等能力按需申请 Android 系统权限。
- 无障碍能力由用户在 Android 系统设置中显式启用。
- 闹钟和日历操作通过系统界面交由用户确认。
- 请只配置自己有权使用的模型服务和 API 凭据，不要将密钥提交到 Git 仓库。
- 设备厂商、Android 版本和第三方服务可能影响具体能力是否可用。
