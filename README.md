# HyperCat AI

**HyperCat AI 是面向 Android 手机的 AI Agent 智能助手。** Agent 主应用可在其他 Android 设备上使用，不要求手机具备背屏；只有背屏虚拟形象投放与互动功能，目标机型包括 Xiaomi 17 Pro / 17 Pro Max、Xiaomi 18 Pro / 18 Pro Max；具体背屏能力仍需结合机型与系统版本进行实机验证。背屏不是独立宠物程序，而是 Agent 的第二交互界面：主屏与背屏共享角色资料、情绪和交互状态。

- **当前版本：** 0.9.42（versionCode 60）
- **平台：** Android
- **技术栈：** Kotlin、Jetpack Compose、Coroutines、Android 系统 API
- **仓库：** [GitHub](https://github.com/yanglin950915-sketch/HyperCatAI-next)
- **版本下载：** [GitHub Releases](https://github.com/yanglin950915-sketch/HyperCatAI-next/releases)
- **构建记录：** [GitHub Actions](https://github.com/yanglin950915-sketch/HyperCatAI-next/actions)

## 项目目标

1. 建立可靠、可扩展的个人 AI Agent，负责理解请求、持续对话、记忆和执行经授权的手机任务。
2. 将二次元虚拟形象作为 Agent 的可视化人格，让表情、动作和语音状态反映 Agent 当前状态。
3. 在支持的 Xiaomi Pro 背屏机型上，将背屏作为可触摸的第二交互终端，实现主屏与背屏双向状态同步和互动；其他 Android 设备继续使用 Agent 主应用。

## 核心功能

### AI Agent
- 支持兼容 OpenAI API 格式的模型服务，可保存多组模型配置并切换。
- 推理模型与 TTS 语音服务分开配置。
- 支持连续对话、历史会话管理、消息分享和附件处理。
- 简单问题优先简洁回答；复杂任务按需提供必要说明。

### 记忆与个性化
- 支持通过对话整理可复用的个人偏好和上下文。
- 支持在应用内管理记忆相关配置。
- 记忆用于改善后续对话连续性；用户可按应用提供的管理入口调整。

### 语音与视觉交互
- 支持语音输入和回复朗读。
- 提供 AI 语音通话界面。
- 支持摄像头预览与视觉模型分析；具体能力取决于设备权限和模型服务。
- 语音识别、TTS 和视觉能力受 Android 系统服务及所配置服务兼容性影响。

### Android 工具能力
- 天气查询：支持 Open-Meteo、高德和​​彩云天气服务配置。
- 闹钟、日历：通过 Android 系统界面交由用户确认。
- 基础手机操作：可选接入 Android 无障碍服务；必须由用户在系统设置中主动授权。
- 位置、麦克风、摄像头等权限按功能需要申请，不会在未授权时执行对应操作。

## 背屏虚拟形象

背屏虚拟形象是 Agent 的延伸界面，不是与 Agent 分离的独立功能。

### 当前基础
- 主屏与背屏共享虚拟形象名称、角色标识、情绪和最新回复等状态。
- 背屏触摸事件可转交主应用处理，并进入 Agent 互动流程。
- Agent 的思考、回复和角色情绪可反馈到虚拟形象展示。
- 背屏内容采用本地资源渲染，尽量减少对网络资源的依赖。
- 背屏投放、系统权限、显示区域和触摸事件受设备厂商系统实现影响，必须在目标机型实测。

### 目标设备与兼容性
**Agent 主应用：** 面向 Android 手机，不限于小米设备；不具备背屏的设备仍可使用对话、记忆、语音及其他已支持的 Agent 功能。

**背屏功能：** 目标机型包括 Xiaomi 17 Pro / 17 Pro Max、Xiaomi 18 Pro / 18 Pro Max。不同机型、HyperOS 版本和主题服务版本可能存在差异；各机型的投放、显示与触摸交互仍需分别进行实机验证，未验证通过的能力会标注为实验性功能，不将文件写入成功等同于背屏已正常显示。

## 接下来开发计划

### 1. 背屏与 Agent 深度交互
- 统一背屏触摸、长按、拖动、语音输入等事件协议。
- 互动事件进入当前 Agent 会话，保留可追溯的消息记录。
- Agent 思考、回复、朗读、空闲、错误等状态及时同步到背屏。
- 完善事件去重、任务排队、前后台切换、断连恢复和异常反馈。

### 2. 二次元虚拟形象升级
- 从简化绘制升级为完整二次元人物立绘，提升面部、发型、服装和身体比例细节。
- 增加眨眼、呼吸、待机、开心、害羞、思考、说话、惊讶和难过等表情动作。
- 主屏与背屏共用角色设定和状态语义。
- 素材使用原创内容或具有明确使用及再分发授权的资源。

### 3. 背屏改为直接触摸互动
- 取消虚拟形象下方的固定操作按钮。
- 通过轻触、长按和拖动角色触发互动。
- 使用角色动作、表情、对话气泡和 Agent 回复提供反馈。
- 优化摄像头开孔避让、误触处理、触摸区域和低功耗策略。

### 4. 实时 3D 背屏体验
参考用户提供的演示主题方向，探索实时角色表现：
- 评估 2.5D 分层视差与实时 3D 两种实现路线。
- 探索视线跟随、头部转动、身体摆动、触摸反馈和轻量物理动画。
- 优化帧率、内存、发热和息屏/AOD 时的资源占用。
- 不直接复制未经授权的角色模型、立绘、动作或音频；先以原创或明确许可素材验证技术方案。

## Live2D 二次元虚拟形象（0.9.42 起）

- 在「虚拟形象」设置中可导入用户自有的 Live2D Cubism ZIP 模型；压缩包需要包含 `.model3.json`、`.moc3` 和贴图目录。
- 主屏资料卡、虚拟形象设置预览与独立背屏 Activity 共用同一模型与 Agent 情绪状态。
- 支持眼球跟随、眨眼、呼吸/待机摆动、开心/难过/害羞/思考/好奇等表情，以及轻触、长按、拖动回传 Agent。
- 云端 TTS 播放时，在麦克风权限已授予的情况下尝试读取播放波形驱动口型；系统 TTS 或无法读取波形时使用轻量说话口型动画。
- 背屏资源包会将当前已导入模型一并打包，重新部署背屏卡片后即可尝试在 MAML WebView 中显示同一模型；不导入模型时仍使用原有轻量 Canvas 角色作为兼容回退。
- 为控制发热和功耗，Live2D 默认限制主屏/背屏 WebGL 渲染帧率（背屏资源包默认 20 FPS，Android 宿主默认 24 FPS）。

### 模型与 SDK 授权
本项目不内置第三方角色模型；用户需要导入本人制作或已获得再分发/使用许可的模型。PixiJS 与 pixi-live2d-display 按各自 MIT 许可保留声明。Live2D Cubism Core 是 Live2D 专有组件，不受本项目 MIT 许可覆盖，需遵守其原始许可与发行规则；公开发布前应核对当前 SDK 发行许可，尤其是允许终端用户导入模型的可扩展应用场景。详见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 权限与隐私
- 麦克风、摄像头和位置权限按需申请。
- 无障碍服务需用户在 Android 设置中主动启用。

## 开发原则
- Agent 是核心，背屏是第二交互终端。
- 优先实现可验证的双向交互闭环，再扩展视觉效果。
- 所有设备能力以真实系统接口和实机测试为准，不伪报成功。
- 优先考虑稳定性、可访问性、低功耗和用户授权。
