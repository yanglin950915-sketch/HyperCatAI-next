## 项目定位

- **主线：AI Agent。** 负责理解用户请求、模型对话、记忆管理、语音交互，以及经授权的手机工具调用。
- **扩展：背屏 AI 虚拟形象。** 通过 REAREye 将 Agent 状态、回复和触摸互动同步到兼容设备背屏。
- **平台：Android。** 以 Kotlin 和 Jetpack Compose 构建，主屏 Agent 与 REAREye 背屏组件共用状态仓库。

## Agent 核心能力

### 大模型对话与配置
- 支持配置兼容 OpenAI API 格式的模型服务。
- 推理模型与 TTS 语音模型分别配置、选择和管理，拥有独立的模型档案及连接参数。
- 支持保存多个模型配置，按需切换或删除。
- 对话支持模型回复、思考内容展示及代码内容的独立呈现等交互体验。

### 记忆与个性化
- 可通过对话明确要求 Agent 记住信息。
- 支持查看、添加、删除单条记忆及清空记忆。
- 已保存的记忆可作为后续对话上下文使用。

### 语音交互与 AI 通话
- 支持回复语音朗读，并可单独控制自动朗读开关。
- TTS 与推理模型分开设置；可使用支持的第三方 TTS 服务。
- 提供应用内语音识别交互和 AI 语音通话界面。
- AI 视频通话支持摄像头预览，并将间隔采集的画面交给视觉模型分析。

> 当前视频交互采用摄像头预览和间隔采帧分析，并非连续双向视频流或 WebRTC 实时音视频通话。语音识别能力依赖 Android 设备上已安装并启用的识别服务；语音播报则依赖已配置且兼容的 TTS 服务。

### 系统工具
Agent 可根据用户请求调用 Android 系统能力或外部数据服务，包括：
- **闹钟：** 调用系统闹钟应用创建/设置闹钟，由用户确认。
- **日历：** 调用系统日历新建事件页面，由用户确认保存。
- **天气：** 支持 Open-Meteo、高德地图和​​彩云天气三种服务，用户可在设置中自主选择；高德 Key、彩云 Token 分别独立保存，也可使用免密钥的原有 Open-Meteo。支持当前位置和城市/区县查询。
- **手机基础操作：** 可选接入 Android 无障碍服务，支持返回、主页、通知栏、快捷设置、滑动和按文字点击等简单操作。

系统操作必须遵守 Android 权限与用户授权。无障碍服务需要用户在系统设置中主动启用；未授权时不会执行对应操作。无线调试/ADB 控制不应被视为当前版本已具备的能力。

## 背屏 AI 虚拟形象（REAREye 接入）

应用内置 Shizuku 直接投放通道：设置 → 虚拟形象伙伴开启投放，按提示授权 Shizuku 后自动识别背屏并启动独立虚拟形象 Activity。主屏与背屏共用 PetStateStore 和 Agent 事件分发器。REAREye/MAML 资源作为兼容模式保留，不再要求常规用户手动导出。

常规背屏投放通过 Shizuku 将同一 APK 内的独立虚拟形象 Activity 启动到背屏，不需要导出 ZIP 或创建 REAREye 卡片；REAREye/MAML 资源保留为兼容模式。主屏与背屏共用 PetStateStore 和 Agent 事件分发器。

背屏与主屏 Agent 共用同一份虚拟形象状态。主应用通过只读 ContentProvider 暴露名称、情绪和最新回复；REAREye 的 MAML 组件负责刷新数据，WebView 负责离线绘制表情与触摸区域。触摸动作通过 MAML WebView 内部 Trigger 回传 Android 广播，经身份校验后交由 WorkManager 排队调用当前 Agent 模型，生成的回复再同步到背屏状态。

- **主屏到背屏：** Agent 思考状态、最终回复、天气/系统操作结果和虚拟形象名称/情绪。
- **背屏到主屏：** 轻触、长按、思考、休息等互动事件通过 WorkManager 持久化排队并调用当前模型；回复会写入最近对话并同步到虚拟形象状态。
- **显示适配：** 904×572 横向设计基准、左侧摄像头避让区、DPR 画布和实际 WebView 视口缩放；AOD/暂停时停止动画。
- **离线资源：** HTML、CSS、JavaScript 内联在一个文件中，不依赖 CDN、外部字体或在线图片。
- **跨应用访问保护：** Provider 仅允许 Android 识别为 `hk.uwu.reareye` 的调用 UID 读取背屏状态；触摸广播通过 Android 14（API 34）及以上的发送方 UID 校验，无法验证发送方的旧系统会拒绝互动事件。

### REAREye 接入流程（依据 v2.0.0 APK 内置工具）

REAREye v2.0.0 的内置工作流不是简单把 ZIP 当 APK 安装：其工具说明要求先通过 `get_widget_spec` 获取规范，再用 `create_html_widget` 创建 HTML 组件，最后用返回的 `business` 调用 `create_card` 添加背屏卡片。

1. 下载 Release 中的 `HyperCatAI-reareye-widget.html`（单文件 HTML）和 `HyperCatAI-rearscreen.zip`（MAML WebView 绑定参考包）。
2. 在 REAREye 自带的 AI 助手中，提供 HTML 文件，要求先调用 `get_widget_spec`，再按 904×572 尺寸调用 `create_html_widget`，标题使用「HyperCat AI」。
3. 取得组件返回的 `business` 后，调用 `create_card` 创建背屏显示卡片；按 REAREye 的确认提示授权创建。
4. **状态同步验证是单独步骤：** MAML 绑定参考包保留了 HyperCat AI ContentProvider 和触摸广播定义。REAREye 的 HTML 创建流程是否允许保留/配置这些绑定，需要在 v2.0.0 实机工作流中验证；若工具只接收 HTML 而不能配置绑定，不要把“卡片创建成功”误认为 Agent 双向同步已成功。

`register_app_card` 是应用启动入口，不等同于显示卡片；仅在你还需要把 HyperCat AI 加入背屏应用启动列表时才额外使用。

- 无障碍能力由用户在 Android 系统设置中显式启用。
- 闹钟和日历操作通过系统界面交由用户确认。
- 请只配置自己有权使用的模型服务和 API 凭据，不要将密钥提交到 Git 仓库。
- 设备厂商、Android 版本和第三方服务可能影响具体能力是否可用。

## 项目方向

HyperCat AI 将持续以 **Agent 能力为第一优先级**：提升模型兼容性、记忆能力、语音交互、工具调用和 Android 任务执行体验；背屏虚拟形象作为可选终端，持续完善设备适配、动作和实机稳定性。


## 0.9.8 更新

- AI 通话遇到 Android SpeechRecognizer 服务中断/服务器断开时，重建识别器实例并自动恢复监听，避免在失效实例上反复调用 startListening。
- 彩云天气地点查询改为多候选地址匹配，降低同名城市/区县误匹配；Android 11 及以上优先请求实时定位；旧版本只接受最近 2 分钟内的缓存定位，避免使用长期未更新的坐标。
- 天气位置无法可靠匹配或定位过期时，明确提示用户补充城市/区县或刷新定位，不再静默使用可能错误的地点。

## 0.9.4 更新

- 修复 AI 通话语音识别监听与结果回传流程。
- 最近对话列表支持单条删除。
- Agent 对话与通话界面移除虚拟形象表情展示，首页虚拟形象功能保留。


## 0.9.5 更新

- 强化 AI 通话麦克风录音权限与系统麦克风隐私开关检查，显示实际语音识别启动状态并改善权限恢复提示。
- AI 通话开始时主动问候；用户暂时没有说话时，会结合当前对话随机自然延续话题。
- 将附件按钮移动到消息输入框右侧。


## 0.9.6 更新

- AI 通话期间保持语音识别持续运行；识别完成后自动重新开启下一轮监听。
- Agent 播报时不再主动取消麦克风识别；结合播报文本过滤疑似自身回声。
- 通话切换 Android 通信音频模式并使用扬声器路由，挂断时恢复原音频设置。
- 增加麦克风输入电平显示，便于判断设备是否实际采集到声音。
- 延长单轮语音静默窗口，减少用户短暂停顿时频繁结束识别。


## 0.9.7 更新

- 输入框右侧改为语音输入按钮；附件按钮移动到底部操作栏，与语音按钮交换位置。
- 天气服务支持三选一：原有 Open-Meteo（免密钥）、高德地图天气（独立 Web 服务 Key）、彩云天气 v2.6（独立 Token）。
- 三种服务配置互不覆盖，用户可在设置中随时切换；凭据仅保存在设备本地。
- 高德使用行政区划编码查询；彩云与 Open-Meteo 使用系统地理编码解析城市/区县坐标。
- 彩云请求按官方要求在中国大陆使用 GCJ-02 坐标；实时、小时/天级预报和预警数据按 Token 套餐权限返回。
