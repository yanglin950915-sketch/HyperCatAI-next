▸手机端详细步骤：Shizuku 激活、小米背屏设置、普通手机玩法与连不上排查 展开查看

1. 小米手机怎么免 Root 激活 Shizuku？

  1. 先扫码装好背屏 AI 桌宠 App，打开后点里面的「下载安装 Shizuku」即可在手机上直接下载安装。
  2. 手机进「设置 → 我的设备 → 全部参数与信息」连点OS 版本打开开发者选项。
  3. 进「更多设置 → 开发者选项」打开 USB 调试、无线调试、USB 调试（安全设置）。
  4. 打开 Shizuku 点「配对」，回「无线调试 → 使用配对码配对设备」把 6 位配对码填进通知栏，再回 Shizuku 点「启动」。
小坑：通知栏看不到输入框时，去「设置 → 通知与控制中心 → 通知显示设置」临时切一次「原生样式」即可。

2. 装好手机 App 后怎么投背屏？

  1. 确保手机和电脑连同一个 Wi-Fi，打开手机上的「背屏 AI 桌宠」，会自动搜到你的电脑并连上。
  2. 点「一键授权 Shizuku」→ 选「始终允许」，然后点「一键投到妙享背屏」，翻转手机即可看到大眼睛！
  3. 若希望正面锁屏时背屏也常亮不退出，打开 App 里的「守护模式」开关，并把 Shizuku 与本 App 省电策略设为无限制。
  4. 没有小米背屏？任意旧安卓手机/平板不用装 Shizuku，直接点 App 底部的「当前屏幕全屏运行 AI 桌宠」；iPhone/iPad 切上方「纯黑背屏网页」扫码即可。

3. 手机扫码打不开 / 报 ERR_TOO_MANY_RETRIES？

  • 换浏览器：别用微信扫码；若手机 Edge / Chrome 报 ERR_TOO_MANY_RETRIES，换小米自带浏览器 / Via，或在浏览器设置里关闭「使用安全 DNS」与「始终使用安全连接」。
  • Windows 电脑：右键以管理员身份运行一次文件夹里的 Windows放行防火墙8765端口.bat。
  • macOS 电脑：去「系统设置 → 隐私与安全性 → 本地网络」确认 终端 已允许访问本地网络。
  • 代理干扰：确认手机未开梯子/VPN，且与电脑在同一 Wi-Fi 网段。

4. 接入 Agent 后背屏没反应 & 背屏手势

  • 没反应先重启软件 & 信任钩子：在卡片 1 点完「一键接入」后，务必完全退出并重开一次对应 AI 软件；如果使用的是 Codex，重启后还需进入 Codex 设置 → Hooks（或在命令行 Codex 输入 /hooks）逐条信任「Mi Rear AI Pet status」钩子（Codex 安全机制默认拦截未信任的外部 Hook）。
  • 背屏手势说明：单击左/右眼眨眼，点眉心雷达审视，左右轻滑触发超频/无语彩蛋，单指长按 2 秒调出校准面板（支持一键重置默认）。
  • 遇到问题反馈：展开手机 App 最底部的「诊断日志」点「复制日志」即可发给作者排查。
